# Contributing

Help improve the Painting TV dataset with better images and accurate,
up-to-date information about the paintings.

- **Better images:** suggest a higher-resolution or clearer reproduction of
  the same painting. Use original reproductions, without upscaling or AI
  generation, and include a link to the source page and any licence or credit
  information available.
- **Updated information:** report corrections to titles, artists, dates,
  movements, holding collections, or source and rights information. Include a
  reliable reference, such as the museum's page for the painting.

Open a GitHub issue or pull request with the painting's title and artist, the
proposed improvement, and supporting links. You can also open a discussion on
the [dataset](https://huggingface.co/datasets/Mateleo/painting-collection/discussions).

For changes to the dataset tooling or catalog files, see
[tools/README.md](tools/README.md) for the collection workflow.
