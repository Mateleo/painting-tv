# Painting TV 0.7.1 — a new look

- A new logo: a P built from rounded screen pixels, in white over Van Gogh's
  *Wheat Field with Cypresses*.
- The launcher icon, the TV home-screen banner and the APK icon shown by file
  managers all use it, edge to edge. The notification and themed (Android 13+)
  icons use the logo alone.

Settings and the downloaded collection are kept. Some launchers cache icons, so
the old one may show until the launcher refreshes. `SHA256SUMS.txt` verifies the
APK download.

This remains a debug-signed personal preview. Validated with the Android build,
JVM unit tests, lint, and Python checks; no TV device test was run for this release.
