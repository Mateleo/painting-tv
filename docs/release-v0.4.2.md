# Painting TV 0.4.2 — French titles and APK icon

- Paintings the source deck names in English now show their French title.
- The APK file now shows the Painting TV icon in file managers and installers,
  in addition to the launcher icon and banner on the TV.

Install `painting-tv-0.4.2.apk` over the previous version to keep your settings
and downloaded paintings; the
[Hugging Face collection](https://huggingface.co/datasets/Mateleo/painting-collection)
is unchanged. `SHA256SUMS.txt` verifies the APK download.

This remains a debug-signed personal preview. Validated with the Android build,
JVM unit tests, lint, and Python checks; no TV device test was run for this release.
